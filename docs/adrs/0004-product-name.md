# ADR 0004: Use Loadout Atelier as the product name

- Status: accepted
- Date: 2026-08-28

## Context

The working title, BuildKeeper, needed a distinct professional identity and repository slug before publication. An exact-name GitHub repository search performed before repository creation returned three BuildKeeper matches. The same search returned zero repositories named Loadout Atelier and zero exact `loadout-atelier` slug matches under the authenticated account.

## Decision

Use **Loadout Atelier** for the product and `loadout-atelier` for the public GitHub repository. “Atelier” reinforces the product's deliberate build-workbench positioning without implying an official Wynncraft relationship.

## Consequences

The name is reasonably distinct for portfolio publication based on the recorded GitHub collision check, but this lightweight check is not trademark clearance. The repository description and application always state that the project is unofficial and unaffiliated.
